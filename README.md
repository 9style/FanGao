# 星夜回声 · Starry Echo

一束来自未来的光，落进了 1889 年的夜空。

将《银翼杀手 2049》全息女孩的视觉语言与梵高《星月夜》的
深蓝旋涡、金色星光融合的全屏交互艺术。所有视觉和声音本地生成，
不需要 API Key、模型下载、外部字体或 CDN。

## 运行

需要 Node.js 20 或更新版本，以及支持 WebGL 2 的现代浏览器。

```powershell
npm run dev
```

打开 **http://localhost:5173**。不需要先运行 `npm install`。

服务默认监听 `0.0.0.0`，也支持通过本机 IPv4 地址访问，例如
**http://192.168.1.100:5173**。同一局域网中的其他设备可打开
`http://<运行服务的电脑IP>:5173`；在 Windows 上运行 `ipconfig`
查看该电脑的 IPv4 地址。更换端口后，访问 URL 也需使用对应端口。

更换端口：

```powershell
$env:PORT = 8080
npm run dev
```

不要直接双击 `index.html`：浏览器的 ES module 加载需要 HTTP 服务。
部署时把 `index.html` 与 `src/` 放在静态站点的根目录即可；
不需要构建步骤或后端。

| --- | --- |

| 点击 / 轻触画布 | 释放金色涟漪 |

| 视角栏 | 自由观察、正面、侧面、背面、面部特写 |

| 播放按钮 / 空格 | 暂停、继续动画 |
| 星流滑块 | 调节流场速度与扰动力 |
| 全息滑块 | 调节投影亮度、透明度与辉光 |
| 色板按钮 | 星夜钴蓝 / 金色与霓虹紫 / 青色切换 |

按钮和滑块获得焦点时，空格保留原生操作，不会触发全局快捷键。
系统启用“减少动态效果”时，场景默认暂停，仍可手动播放。
切到后台时模拟计时与声音停止，返回时不会突然快进。

### 自由观察

普通拖动、滚轮与键盘操作从当前相机继续观察，保留原构图、标题
和人物旁白，不会在第一次操作时把人物突然移到页面中心。
点击“自由观察”或正面、侧面、背面、特写预设，才主动切换到居中
的沉浸模式并淡出文案；“恢复构图”返回初始视角。
水平方向支持连续多圈环绕；俯仰限制
在 ±75°，避免越过极点导致视角翻转。缩放范围为 2.6–22 个场景单位，
并检查相机是否进入人物的扩展包围体。平移方向跟随当前相机，
因此在侧面或背面观察时仍然符合屏幕方向。

暂停只冻结星流和呼吸等模拟，仍可旋转、缩放、平移和切换视角。
模型网格、表面粒子、投影光环及菲涅尔光晕使用同一真实 3D 相机；
点击位置随视角投影到当前观察平面，不使用固定屏幕坐标近似。
首次操作会继承原相机位置、朝向和画面偏移，而不是重新套用正面
预设；后续环绕和缩放保持已有的画面锚点。

这是**观察视角控制**，并非骨骼姿势编辑；没有增加转头、抬手等
独立关节控制。不支持 WebGL 的轻量二维模式提供缩放和平移，
明确禁用三维环绕及侧面、背面预设，不模拟不存在的立体效果。

## 实现

- **原创程序化 3D 人物**：椭圆截面长裙、面部细节、长发曲线、
  抬手和指尖；面积加权三角形采样产生贴合表面的笔触粒子。
- **双层全息材质**：半透明人物网格、菲涅尔边缘光、扫描线、
  呼吸变化、偶发局部信号位移与沿发梢 / 裙摆消散的粒子。
- **星夜流场**：多组旋涡、细长多鬃笔触、月牙、星点与投影环；
  鼠标排斥和点击波纹在 GPU 中实时计算。
- **后处理**：低分辨率阈值提取、双向模糊 Bloom、轻微色散和暗角。
- **适配**：限制像素比、移动端降低粒子数量、慢设备降低渲染分辨率。
  不支持 WebGL 2 时显示可交互的 2D 轻量版本。
- **声音**：Web Audio 本地合成的柔和持续音，只在主动点击后启用。

本环境无法连接搜索网站、MoMA 或 npm registry，也没有可用的图像
生成工具。因此，没有下载网络图片、GLB 或演员肖像；人物是风格化
原创雕塑，不是电影级真人模型。

原方案中的 Three.js 在本环境无法下载，当前用原生 WebGL 实现相同
效果，不依赖 Three.js。若后续使用有明确许可的女性 GLB，可将
`src/geometry.js` 中的网格输出与表面采样输入替换为解码后的顶点、
法线、索引数据，保留材质、交互和后处理；GLB 解码器和骨骼蒙皮
需要另行接入，目前没有声称支持直接拖入 GLB 或 Mixamo 动画。

## 项目结构

```text
index.html              页面、控制栏与作品介绍
server.mjs              零依赖本地静态服务
src/main.js             输入、控件、动画时钟与生命周期
src/state.js            设置验证、暂停计时与指针投影
src/camera.js           自由相机、预设、边界与屏幕 / 世界投影
src/orbit-controls.js   鼠标、触屏、双指手势与取消清理
src/math.js             确定性随机数、向量与相机矩阵
src/geometry.js         人物几何与面积加权表面采样
src/shaders.js          星空、全息、笔触与 Bloom 着色器
src/renderer.js         GPU 资源与后处理管线
src/fallback.js         2D 降级画布
src/audio.js            可选环境音
src/style.css           自适应视觉布局
tests/                  单元测试与真实浏览器测试
```

## 验证

```powershell
npm test
```

浏览器测试需要 Playwright Core 和本地 Chrome。开发环境已使用
本机缓存恢复 Playwright Core 至 `.cache/playwright/package`；
这个开发工具不是页面运行依赖。

其他环境可在网络可用时安装测试工具：

```powershell
npm install --no-save playwright-core
npm run dev
```

另一个终端运行：

```powershell
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:browser
```

测试覆盖真实 WebGL 启动、交互、暂停、滑块、色板、重置、介绍弹窗、
键盘、声音、移动端触控、减少动态效果，以及无 WebGL 降级。
相机测试覆盖连续环绕、俯仰 / 缩放边界、相机朝向下的平移、近距离
安全检查与投影往返；自由观察浏览器测试覆盖真实鼠标拖动、滚轮、
右键 / Shift 平移、视角预设、暂停时控制及 Chrome 触屏双指手势。
截图输出到 `artifacts/`。
